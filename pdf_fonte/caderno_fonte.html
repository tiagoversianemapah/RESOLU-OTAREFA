1)Cifra de Hill: DOGS

$K=\begin{pmatrix}2&1\\25&4\end{pmatrix}$, módulo 26. Blocos: DO $=(3,14)$ e GS $=(6,18)$.

Cifrar ($C = K\cdot P \bmod 26$):

$$\begin{pmatrix}2&1\\25&4\end{pmatrix}\begin{pmatrix}3\\14\end{pmatrix}=\begin{pmatrix}2\cdot3+1\cdot14\\25\cdot3+4\cdot14\end{pmatrix}=\begin{pmatrix}20\\131\end{pmatrix}\equiv\begin{pmatrix}20\\1\end{pmatrix}\ \to\ \text{UB}$$ $$\begin{pmatrix}2&1\\25&4\end{pmatrix}\begin{pmatrix}6\\18\end{pmatrix}=\begin{pmatrix}2\cdot6+1\cdot18\\25\cdot6+4\cdot18\end{pmatrix}=\begin{pmatrix}30\\222\end{pmatrix}\equiv\begin{pmatrix}4\\14\end{pmatrix}\ \to\ \text{EO}$$

Texto cifrado: UBEO

Inversa de K:

$\det K = 2\cdot4-1\cdot25=-17\equiv 9 \pmod{26}$

$9^{-1}\bmod 26 = 3$, pois $9\cdot3=27\equiv1$

$$K^{-1}=\det(K)^{-1}\cdot\operatorname{adj}K = 3\begin{pmatrix}4&-1\\-25&2\end{pmatrix}=\begin{pmatrix}12&-3\\-75&6\end{pmatrix}\equiv\begin{pmatrix}12&23\\3&6\end{pmatrix}\pmod{26}$$

Decifrar ($P = K^{-1}\cdot C \bmod 26$):

$$\begin{pmatrix}12&23\\3&6\end{pmatrix}\begin{pmatrix}20\\1\end{pmatrix}=\begin{pmatrix}263\\66\end{pmatrix}\equiv\begin{pmatrix}3\\14\end{pmatrix}\to\text{DO}\qquad \begin{pmatrix}12&23\\3&6\end{pmatrix}\begin{pmatrix}4\\14\end{pmatrix}=\begin{pmatrix}370\\96\end{pmatrix}\equiv\begin{pmatrix}6\\18\end{pmatrix}\to\text{GS}$$

Mensagem decifrada: DOGS

5)Quebra da cifra afim

Em inglês, as letras mais frequentes são E $(4)$ e T $(19)$. Logo, E $\to$ B $(1)$ e T $\to$ U $(20)$:

$$\begin{cases}4a+b\equiv 1 \pmod{26}\\ 19a+b\equiv 20 \pmod{26}\end{cases}$$

Subtraindo: $15a\equiv 19 \pmod{26}$. Como $15^{-1}\bmod 26=7$ (pois $15\cdot7=105\equiv1$):

$$a\equiv 19\cdot 7=133\equiv 3 \qquad b\equiv 1-4\cdot3=-11\equiv 15$$

$\operatorname{mdc}(3,26)=1$, então a chave é válida.

$$e(x)=3x+15 \bmod 26 \qquad\qquad d(y)=9\,(y-15)\bmod 26$$

6)Cifra de bloco × cifra de fluxo

A cifra de bloco divide a mensagem em blocos de tamanho fixo e cifra cada bloco inteiro de uma vez, com a mesma chave (ex.: Hill, DES, AES).

A cifra de fluxo cifra a mensagem bit a bit (ou caractere a caractere), combinando cada símbolo com uma sequência de chave que muda a cada posição (ex.: LFSR, RC4, auto chave). Em geral é mais rápida e simples de implementar em hardware.

9)Cifra polialfabética × monoalfabética

A monoalfabética usa um único alfabeto de substituição, então cada letra do texto claro vira sempre a mesma letra cifrada (ex.: César, afim). Ela mantém a frequência das letras do idioma e pode ser quebrada por análise de frequência.

A polialfabética usa vários alfabetos de substituição, então a mesma letra pode virar letras diferentes, dependendo da posição ou da chave (ex.: Vigenère, auto chave). Ela disfarça as frequências e é mais difícil de quebrar.

10)Valores de $a$ não permitidos em $E(x)=ax+b \bmod 47$

Para a função ter inversa, é preciso que $\operatorname{mdc}(a,47)=1$. Como 47 é primo, isso vale para qualquer $a$ que não seja múltiplo de 47.

Portanto, o único valor não permitido é $a\equiv 0 \pmod{47}$. Os valores $a=1,2,\ldots,46$ são todos permitidos.

11)Criptografia ou esteganografia?

O exemplo usa as duas técnicas. Codificar as mensagens com uma chave que o agente conhece é criptografia, porque esconde o conteúdo da mensagem. Esconder a mensagem verdadeira numa cápsula sob a pele é esteganografia, porque esconde a existência da mensagem. A mensagem falsa serve para enganar quem interceptar o portador.

13)Implementação da cifra afim (Python)

def cifrar(msg, a, b):
    return ''.join(chr((a*(ord(c)-65) + b) % 26 + 65) for c in msg)

def decifrar(cif, a, b):
    ai = pow(a, -1, 26)          # inverso de a mod 26
    return ''.join(chr(ai*(ord(c)-65-b) % 26 + 65) for c in cif)

print(cifrar("OBTER", 3, 7))     # XKMTG
print(decifrar("XKMTG", 3, 7))   # OBTER

14)Implementação da cifra de Hill (Python)

from sympy import Matrix

def hill(K, txt):
    n = K.shape[0]
    v = [ord(c)-65 for c in txt]
    out = []
    for i in range(0, len(v), n):
        out += [x % 26 for x in K * Matrix(v[i:i+n])]
    return ''.join(chr(x+65) for x in out)

K = Matrix([[2, 1], [25, 4]])
c = hill(K, "DOGS")                # UBEO
print(c, hill(K.inv_mod(26), c))   # DOGS

15)Implementação da cifra de fluxo auto chave (Python)

def cifrar(msg, k):
    out = ''
    for c in msg:
        m = ord(c) - 65
        out += chr((m + k) % 26 + 65)
        k = m                      # próxima chave = letra atual do texto claro
    return out

def decifrar(cif, k):
    out = ''
    for c in cif:
        m = (ord(c) - 65 - k) % 26
        out += chr(m + 65)
        k = m
    return out

print(cifrar("ENCRYPTION", 20))     # YRPTPNIBWB
print(decifrar("YRPTPNIBWB", 20))   # ENCRYPTION
